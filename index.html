LOGIQ Downloader

Scarica i dati dalla XIAO via Bluetooth — tutto dal telefono.

Come si usa
  1. XIAO accesa a batteria (switch ON) e scollegata dal Mac.
  2. Connetti → scegli LOGIQ-log.
  3. Scarica dati → attendi la barra.
  4. Il file finisce nello Storico qui sotto e puoi condividerlo subito.
  5. Per liberare la memoria per la prossima sessione: Azzera.
  6. Sul PC: seleziona più esportazioni nello Storico → Esporta ZIP.
Durante lo scarico, sulla XIAO il LED blu lampeggia; si spegne a fine download.
